# 快科技自动出题·操作手册

定时任务（QoderWork 每周执行）自动从快科技抓取最新硬件资讯并转换为题目，合入题库。
本文件是给执行任务的 AI 助手看的完整流程，也方便老师了解/手动复现。

## 题目格式（严格遵守，否则合并校验会失败）

每道题的 JSON 字段**必须且只能是**这 6 个键：

```json
{
  "category": "硬件资讯与新品动态",
  "q_type": "mc",
  "question": "题干（以新闻事实为依据）",
  "options": ["选项1", "选项2", "选项3", "选项4"],
  "answer": "B",
  "explanation": "解析（说明正确答案的依据，可带新闻背景）"
}
```

硬性规则：
- 分类固定为 `硬件资讯与新品动态`
- `q_type` 只能是 `mc`（单选，恰好 4 个不重复选项）或 `tf`（判断题，选项固定为 `["正确", "错误"]`，answer 为 `"A"`=正确 / `"B"`=错误）
- 单选题答案为 `"A"`/`"B"`/`"C"`/`"D"`，一批题中四个字母要**均衡分布**（数量差不超过 1）
- 选项内**不能**带 "A."、"B、" 这类字母前缀（系统会自动加）
- 题干不能与现有题库重复（含空格归一化后的比较）
- 干扰项要合理（同类型、同量级、似是而非），不能一眼假
- 解析必须非空，说明依据

## 出题内容要求

- 来源：快科技 https://news.mydrivers.com/ （抓首页最新资讯即可，注意当天日期，
  首页日报地址形如 https://news.mydrivers.com/doc/YYMMDD.htm）
- 只选**硬件相关**新闻：CPU、显卡、内存、硬盘/SSD、主板、电源、显示器、外设、
  整机/笔记本、手机芯片、国产硬件进展等
- 跳过：纯软件更新、游戏、价格促销口水战、无具体技术点的内容
- 优先有**明确技术参数/事实**的新闻（型号、容量、接口、架构名、数字指标），
  便于出成客观题
- 每批 10~20 题，其中判断题不超过 1/3
- 题干尽量带新闻背景（如"据快科技报道，…"），与旧题库的基础知识题区分开
- 时效性措辞注意：写"近期/最新一代"而不是绝对化的"当前最强"，避免很快过时

## 执行步骤

1. 抓取快科技首页（https://news.mydrivers.com/），提取硬件类新闻标题+要点
2. 按上述格式生成一批题，写入
   `scripts/new_questions/mydrivers_YYYYMMDD.json`（用当天日期命名）
3. 运行合并脚本（在项目根目录）：
   `py scripts/merge_new_questions.py`
   - 输出 `MERGED OK` 才算成功；`FAILED errors=N` 则按报告修复后重跑
   - 报告在 `merge_report.txt`
4. 运行审计脚本：`py scripts/audit_questions.py`
   - 要求 `errors=0`；warnings 需检查（分类重复出现等）
5. 通知用户：本次新增几题、来源新闻主题、提醒老师在管理后台点
   **⟳ 同步题库** 按钮（服务器不重启即可生效，学生端立即可抽到新题）

## 注意事项

- Windows 环境：用 `py` 而不是 `python`；中文输出加环境变量 `PYTHONIOENCODING=utf-8`
- `scripts/new_questions/` 下已合并过的批次文件要移入 `merged/` 子文件夹，
  否则下次合并会因重复题干而失败
- 合并脚本现在支持新分类自动追加到题库末尾，无需手动插入
- 若抓取快科技失败（网络波动），直接报告失败原因，**不要**编造新闻出题
- 禁止把促销价格类"今日特价"出成题目（过时太快）
