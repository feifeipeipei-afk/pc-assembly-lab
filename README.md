# 计算机安装与维修在线刷题系统

一个基于 Flask、SQLite 和原生 HTML/CSS/JavaScript 的课堂刷题系统，包含学生答题端和教师管理后台。

## 功能

### 学生端

- **花名册模式**：老师导入班级学生名单后，学生只能从名单中选择自己的姓名登录，防止乱注册、乱填名字捣乱（可在管理后台关闭，恢复自由注册）
- **正式考试**：随机抽取 50 道题，限时 90 分钟，计入班级等级榜
- **考试管控**：老师可设定考试时段（窗口外禁止开考，进行中的不受影响）与次数上限；正式考试中切屏/切出会被静默记录并在管理端标红
- **分类练习**：按分类自选题量（10/20/30 题），不限时，答完立即显示对错与解析，同样获得经验
- **错题本**：自动汇总考试与练习中的错题，展示正确答案与解析，支持一键"错题重练"
- **经验与等级系统**：答对得经验，王者荣耀式 30 级段位（青铜Ⅳ → 最强王者）；首页等级卡片展示段位、升级进度、班级排名与平时成绩折算分；升级触发庆祝动画
- **⚔ 战斗竞技场（课间训练专用）**：火焰纹章风格战斗画面，答题即出招——详见下节

### ⚔ 战斗竞技场（PVP / PVE）

课间训练专用模式，不计入考试；可在管理后台一键关闭（`battle_enabled` 开关）。答对即攻击对手（连击 ≥3 触发"会心一击"演出），PVE 闯关答错会被 Boss 反击掉血。

- **🏰 闯关模式（PVE）**：16 个分类即 16 关，通关上一关解锁下一关；每关 10 题，按正确率评星（一星 ≥60% / 两星 ≥70% / 三星 ≥90%）
- **🎮 三星加成**：集满三星的关数按占比折算进平时成绩，全部三星最多 **+5 分**（与等级折算分并列展示）
- **👤 影子对战（异步 PVP）**：排位赛随机 10 题成绩录成"影子"，同班同学可随时挑战；影子按对方原题原时间轴实时"出手"，比答对数、同分比用时
- **🎯 训练假人（PVE 热身）**：青铜/白银/黄金三档假人，影子目标递增，不计天梯分
- **🏆 班级天梯榜**：胜 +5 / 平 +2 / 负 +1（输也有参与分），假人不计分
- 战斗中经验照常按防刷分规则发放（每日衰减、重复题惩罚同样生效）；断线/刷新后回到战场可续战
- 键盘 `A`–`D` 出招，出招后自动进入下一回合；`←`/`→` 回看战况
- 答案逐题保存到服务器，断线/刷新后可继续答题
- 键盘操作：`A`–`D` 选择答案、`←`/`→` 切换题目、`Esc` 关闭弹窗
- 交卷后展示成绩圆环、本轮经验结算、分类正确率统计和错题回顾；历史成绩可点击回看详情
- 本班等级排行榜：按总经验排序（考试与练习都计入），展示段位与达标状态

### 战斗画面渲染器（可切换）

战斗画面支持两套渲染器，可在不改动任何战斗逻辑的前提下切换：

| 渲染器 | 说明 |
| --- | --- |
| `dom`（默认） | 原生 DOM + CSS 动画，纯离线零依赖，行为与历史版本一致 |
| `three` | Three.js（WebGL）舞台：切图骨骼角色 + 着色器舞台 + 事件驱动演出（顿帧/特效/镜头/飘字） |

切换方式：在学生端 URL 后加 `?renderer=three`（选择会记到 localStorage，之后一直生效），
加 `?renderer=dom` 可切回。WebGL 不可用时会**自动回落**到 `dom` 并在控制台给出原因，不会白屏。

- Three.js 以**本地 vendored** 方式引入（`static/vendor/three/`，r186），**不依赖 CDN、不需要联网、无需构建**
- 渲染与动画代码全部分模块放在 `static/js/battle/`，用浏览器原生 import map 加载 ES 模块
- 默认走 `dom` 时**不会下载** Three.js（约 2MB），探测通过后才按需加载
- 战斗视图不可见时不渲染（省电）；离开战斗会释放全部 GPU 资源

`three` 模式的动画体系（`static/js/battle/`）：

- **舞台**（`renderer/`）：StageScene 用 1 个全屏 quad + 片元着色器画天空渐变/网格线/地面条（替代 3 条 CSS 规则，颜色逐字节对齐旧版）；RendererHost 管帧循环、正交相机、DPR 钳制与 resize
- **角色**（`units/`）：`tools/build_battle_assets.py` 把整图切成部件图集，UnitView 按 rig 定义分层驱动（躯干/头/四肢/武器各自摆动），部件矩形烘进 UV 共用一份材质，待机呼吸分层滞后
- **演出编排**（`anim/`）：Choreographer 把业务事件（命中/会心/连击/影子对手出招）展开成时间轴 —— 突进、命中顿帧（hit-stop）、受击闪白；业务层通过 `battleDispatch` 派发事件，three 活着才消费，否则回落旧 DOM 演出，**两套渲染器互斥、绝不双重演出**
- **特效**（`fx/`）：ImpactFX 维持斩击弧光/命中闪光/冲击环/扬尘的 quad 与粒子池（粒子数受 BUDGET 预算钳制）；CameraDirector 负责命中瞬间的镜头推近与震屏
- **HUD**（`hud/`）：伤害飘字/会心横幅/连击提示仍走 DOM，但由 HudLayer 用 worldToScreen 投影定位到角色头顶，跟随镜头
- 世界单位恒等于 CSS 像素（scale=1），角色大小不随窗口尺寸漂移

### 经验与等级规则（防刷分设计）

- 每答对 1 题基础经验 10 点；每天前 15 题足额、16~30 题减半、之后骤减（防考前突击）
- 同一题首次做对得全额；之前做过（无论对错）再对只计 30%，第三次起为 0（防"先乱答看答案再重刷"）
- 升级所需经验随等级递增；达到**合格等级（默认 20 级·星耀Ⅳ，共需 2850 经验）**视为平时成绩合格
- 等级折算平时成绩：1 级 = 0 分，合格等级 = 60 分，满级（30 级）= 100 分
- 经验从系统启用时开始累计，历史答题不回溯发放
- 经验的"每日"界限按北京时间计算

### 管理后台（/admin）

- 成绩列表：按姓名/班级搜索、按类型（考试/练习）筛选、真分页（20 条/页）、删除记录；正式考试记录显示**切屏次数**（1~2 次橙色、3 次以上红色）
- **考试监控**：正在答题的学生实时列表（进度、剩余时间、切屏次数，10 秒自动刷新）；设置考试起止时段与次数上限
- 数据统计：成绩分布、班级平均分、考试完成率、每日趋势 4 张图表 + **学情分析**（分类正确率排行、易错题 Top 20、单个学生的正确率/经验成长曲线），支持按考试/练习/全部切换
- **平时成绩**：全体学生等级/经验/班级排名/折算分数总表；合格等级可调（2~30 级），实时影响学生端合格判定
- **学生管理**：花名册增删改、按行批量导入名单、重名合并、清零经验；花名册模式开关
- 班级管理：增删改
- **⟳ 同步题库**：题库文件更新后（如自动出题任务合入新题）点击即可生效，无需重启服务器
- **⚔ 战斗竞技场开关**：一键开启/关闭学生端竞技场入口（关闭后课间只保留考试与练习）
- 修改管理密码、退出登录、登录失败限流（连续 5 次锁定 1 分钟）
- Excel 导出：成绩汇总（仅考试，含切屏次数）+ 详细记录（含练习，标注类型与范围）+ 平时成绩（等级折算）三个 Sheet

### 题库

- 共 1790 题、16 个分类，单选约 80%、判断约 20%，每题附解析
- 单选答案位置 A/B/C/D 均衡分布（各约 25%），防止"蒙 A/B"
- 修改 `questions.json` 后**无需重启**：管理后台点击「⟳ 同步题库」即增量入库，学生历史成绩与答题记录完整保留（重启也会自动同步）
- 题库审计脚本：`py scripts/audit_questions.py` 校验格式、重复、答案分布
- **快科技自动出题**：AI 助手定时任务每周一 8:00 抓取快科技（mydrivers.com）最新硬件资讯，自动生成 10~20 道新题合入「硬件资讯与新品动态」分类，题库随硬件行业动态持续更新；流程见 `scripts/AUTO_NEWS.md`

## 运行方式

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python app.py
```

> 本机环境若 `python` 命令不可用，请改用 `py app.py`（py launcher）。

启动后访问：

- 学生端：http://localhost:5001
- 管理后台：http://localhost:5001/admin

环境变量：`PORT`（默认 5001）、`QUIZ_DB_PATH`（数据库路径）、`QUIZ_DEBUG=1`（开启调试模式，生产环境勿开）。

## 测试

```bash
pip install pytest
py -m pytest tests/ -v
```

覆盖登录（花名册拦截）、考试判分、练习即时反馈、错题聚合、增量同步不丢成绩、同步题库接口、经验发放与重复衰减、等级折算、经验排行榜、合格等级设置、考试时段/次数管控、切屏记录、考试监控、学情分析、学生增删改与合并、管理端鉴权与改密、竞技场闯关评星与三星加成、影子录制与挑战、训练假人、天梯计分、竞技场开关与幂等交卷等 39 项测试。

另有 UI 冒烟脚本 `smoke_battle_ui.py`（Playwright）：登录 → 竞技场 → 闯关 → 连答 10 题 → 战斗结算全流程验证，需先启动服务器（`PORT=5099`）。

战斗渲染器冒烟脚本 `smoke_battle_render.py`（Playwright + 内置测试服务器，直接 `py smoke_battle_render.py` 即可）：dom/three 双模式回归 —— dom 确认零影响，three 做像素级校验（天空/网格/地面/角色配色比对）与逐帧演出验收（出招突进位移、命中顿帧 timeScale 归零与恢复、镜头推近/震屏、HUD 飘字投影定位、两套渲染器互斥不双重演出）。

## 安全须知

- 首次启动默认管理密码为 `admin123`，**登录后请立即在后台右上角"修改密码"中更换**
- 密码以哈希存储于数据库 settings 表，忘记密码可删除数据库中 `admin_password_hash` 记录后重启（恢复默认）
- 服务器默认以非调试模式运行；调试模式会暴露交互式控制台，仅限本机调试使用
- 面向课堂局域网使用；如需公网部署，请置于 HTTPS 反向代理之后并使用 waitress/gunicorn 等 WSGI 服务器

## 项目结构

```text
app.py                  Flask 后端和 API（增量题库同步、考试/练习/错题本、经验与等级系统、花名册与考试管控、学情分析、战斗竞技场 PVP/PVE）
smoke_battle_ui.py      竞技场 UI 冒烟测试（Playwright）
smoke_battle_render.py  战斗渲染器冒烟测试（dom/three 双模式 + 像素级校验）
questions.json          题库数据（1790 题）
scripts/                题库维护脚本（审计、修复、重排、合并新题）
scripts/AUTO_NEWS.md    快科技自动出题任务操作手册
scripts/new_questions/  新题源文件（待合并；已合并的批次移入 merged/）
templates/              页面模板（index 学生端 / admin 管理端 / admin_login 登录）
static/css/app.css      公共设计系统样式
static/js/battle/       战斗渲染与动画体系（ES 模块，含渲染宿主、舞台、动画运行时、特效）
static/battle/          战斗角色美术资源
static/vendor/three/    本地 Three.js r186（离线可用，含 addons）
static/vendor/          其他本地第三方库
tests/                  pytest 自动化测试
requirements.txt        Python 依赖
```

## 注意

- 本地运行会生成 `quiz_app.db`（数据库）与 `.secret_key`（会话密钥）文件，均已加入 `.gitignore`；`.secret_key` 保持不变时重启服务器不会导致用户掉线
- 题库修改后点击后台「⟳ 同步题库」或重启服务即自动增量同步，不会清空学生成绩
- 数据库内时间以 UTC 存储，所有展示（学生端、管理端、Excel 导出）均已按北京时间转换
